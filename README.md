# Travel with Me

**Travel with Me** is a comprehensive mobile app designed to simplify travel planning by managing flight and hotel details while recommending personalized attractions based on user destinations.

## Features

- **Flight & Hotel Management**: Add and organize flight and hotel information.
- **Personalized Attractions**: View and filter attractions based on the selected destination city.
- **Location-Based Services**: Get attraction recommendations based on real-time location data.
- **Calendar Integration**: Add events like "Arrival" and "Departure" directly to the calendar.
- **User-Friendly Interface**: Simple, intuitive design for a seamless travel planning experience.
- **Multi-City Travel Plans (Future)**: Plan and manage trips across multiple destinations.

## Tech Stack

- **Kotlin**: For Android app development.
- **Android Studio**: Integrated development environment.
- **Firebase**: For user authentication and data storage.
- **Room Database**: Local storage for attractions and user data.
- **Google Play Services**: For GPS and location-based features.
- **REST API**: For fetching data from external sources.

## Usage
1. Sign up or log in to the app.
2. Add flight and hotel details in the respective sections.
3. Choose a destination to view attractions.
4. Filter attractions by category or view all available options.
5. Add selected attractions and events to your calendar.
